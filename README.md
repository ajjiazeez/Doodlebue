# Doodleblue

A collection of beginner-friendly HTML, CSS, and JavaScript practice work. The main project is a static campus events website; the repository also contains smaller HTML pages and JavaScript exercises.

## Campus Events website

The site is built with plain HTML and CSS and does not require a build step or a backend.

- `index.html` - Home page with featured events and categories.
- `about.html` - Information about the site and its event types.
- `events.html` - List of upcoming events.
- `event-details.html` - Details for Tech Fest 2026.
- `schedule.html` - Event dates, times, venues, and categories.
- `register.html` - Event registration form layout. Submissions are not sent to a server.
- `style.css` - Shared styles for the website.

## Other practice files

- `example.js` and `script.js` - JavaScript exercises covering arrays, objects, destructuring, spread syntax, and nullish coalescing.
- `first/` - Additional standalone HTML and CSS exercises.
- `first/style1.css` - Stylesheet used by the practice pages in `first/`.

## Run locally

Open the root `index.html` file in a web browser to view the Campus Events website. You can also open any other HTML file directly. No package installation or server is required.

Some pages load images from Unsplash, so an internet connection is needed to display those images.
